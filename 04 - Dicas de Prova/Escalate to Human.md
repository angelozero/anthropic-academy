# Escalate to Human

- Sempre avaliar na pergunta o status atual do pedido ou da situaçao do cliente
- Se o status ja esta completo e ja esta ok para a devolucao devido a relamacao - informar a frutracao e oferecer para resolver ou escalar para um humano
- Instruir o agente a escalar para o humano quando o cliente pedir, quando o problema exige excecoes de regras ou o agente nao consegue realizar o processo
- Antes de escalar para um humano sempre tenha em mente que o contexto precisa de algumas informacoes necessarias como customer_id, root_cause, redunf e acao_recomendada
- O modelo conseguiu executar todos os processos e os agentes também mas ha dois dados conflitandos dos quais nenhum consegue chegar a um veredito final, isso precisa ser escalado para um humano resolver
- Se for escalar para o humano ANTES o agente precisa ter contexto
